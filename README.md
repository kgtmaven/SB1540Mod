# Sound Blaster R3 / Audigy 6 USB Driver & Control Panel Mod

${\color{red}WARNING! \space Use \space At \space Your \space Own \space Risk!}$

This project provides a modified driver and a modified control panel for Sound Blaster R3 / Audigy 6 USB sound cards, which otherwise do not support the 'SBX Pro Studio Surround' and 'SBX Pro Studio Dialog Plus' effects.

<br/><br/>
<img width="882" height="637" alt="image" src="https://github.com/user-attachments/assets/2f23258c-4a46-4db3-9e96-865a36be8497" />
<br/>

For the Sound Blaster R3 / Audigy 6 USB sound cards, effects that were originally supported are implemented via hardware processing, while those that were not originally supported are implemented through software processing.

<br/>

## Installation
Go to the Releases page and download the zip file. and extract the files, and reboot in 'Disable driver signature enforcement' mode. then run "setup.exe".

<br/>

## Notes
 - When installing the driver, you must boot in 'Disable driver signature enforcement' mode.
